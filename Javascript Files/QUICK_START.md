## ❓ FAQs

**Q: Can I customize it?**  
A: Yes! Edit the colors, text, and questions directly in `index.html`

**Q: Is my data saved?**  
A: Quiz scores reset on page refresh (demo mode). For persistence, you'd need a backend database.

**Q: Can I add more questions?**  
A: Yes! Search for `quizQuestions` in `index.html` and add more objects.

**Q: How do I change login credentials?**  
A: Search for `"admin" && pass === "1234"` and change the values.
