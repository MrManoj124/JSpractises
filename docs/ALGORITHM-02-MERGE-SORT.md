# Algorithm: Merge Sort

## Time Complexity
- **Best Case**: O(n log n)
- **Average Case**: O(n log n)
- **Worst Case**: O(n log n)
- **Space Complexity**: O(n)

## Description
Merge Sort uses divide-and-conquer by recursively splitting the array in half and merging sorted subarrays.

## Characteristics
- **Guaranteed O(n log n)**: Always performs well
- **Stable Sort**: Maintains order of equal elements
- **Extra Space**: Requires O(n) additional space
- **Best For**: Consistent performance guarantee

## When to Use
- When you need guaranteed O(n log n)
- External sorting scenarios
- Linked lists
- When stability is required
- When worst-case matters

## Performance Notes
- More space used than Quick Sort
- Consistent performance regardless of input
- Better for nearly-sorted data than Quick Sort
