# Feature: Dataset Statistics

## Overview
Display summary statistics about the input dataset for context.

## Statistics Displayed

### 1. Array Size
- Total count of numbers
- Element count

### 2. Min Value
- Smallest number in dataset
- Using Math.min()

### 3. Max Value
- Largest number in dataset
- Using Math.max()

### 4. Average Value
- Mean of all numbers
- Calculated as sum/count
- Rounded to 2 decimals

## Visual Presentation
- Stat cards layout
- Color-coded design
- Large readable values
- Card format with labels

## Benefits
- Quick dataset overview
- Understanding data range
- Contextual information
- Performance expectations

## Implementation
- Statistics calculation in `updateResultsTab()`
- DOM element updates
- Card-based display
- Real-time updates
