# Feature: Chart Visualization

## Overview
Multiple interactive chart types to visualize sorting algorithm performance.

## Chart Types

### 1. Bar Chart
- Horizontal bars for each algorithm
- Easy comparison of values
- Color-coded by algorithm
- Best for single metric view

### 2. Line Chart
- Trends and patterns
- Performance over multiple runs
- Easy to spot outliers
- Good for time-series data

### 3. Radar Chart
- Multi-dimensional comparison
- All algorithms at once
- Visual pentagon/polygon shape
- Best for comprehensive overview

## Features
- Real-time updates
- Smooth animations
- Responsive sizing
- Legend included
- Tooltip information
- Chart.js integration

## Implementation
- Chart.js v4.4.0 library
- Dynamic dataset creation
- Color schemes for clarity
- Canvas-based rendering
