# Installation and Setup Guide

## Getting Started

### No Installation Required!
The Accuracy Analyzer runs directly in your browser - no setup needed.

## How to Access

### Method 1: Direct File Access
1. Download all files from the repository
2. Navigate to: `Javascript Files/Sorting/`
3. Open `index.html` in your web browser
4. Click "Open Analyzer"

### Method 2: Local Server (Optional)
For better performance with larger datasets:
```bash
# Using Python 3
python -m http.server 8000

# Then visit: http://localhost:8000/Javascript Files/Sorting/index.html
```

### Method 3: Online Hosting
Upload files to web server, access via URL.

## System Requirements
- Modern web browser (Chrome, Firefox, Safari, Edge)
- JavaScript enabled
- Internet connection (for Chart.js CDN)
- No additional software needed

## File Structure
```
Javascript Files/Sorting/
├── index.html                  # Start here
├── Accuracy-Analyzer.html      # Main tool
├── Accuracy-Analyzer.js        # Logic
├── Sorting.css                 # Styling
└── docs/                       # Documentation
```

## Quick Start
1. Open `index.html`
2. Click "Open Analyzer"
3. Enter numbers or select preset
4. Click "Analyze"
5. View results and recommendations
6. Export if needed
