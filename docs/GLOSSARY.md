# Glossary of Terms

## Sorting Algorithms
- **Algorithm**: Step-by-step procedure for solving a problem
- **Sorting**: Arranging elements in order (ascending/descending)
- **In-Place**: Sorting without extra memory
- **Stable**: Equal elements maintain relative order

## Performance Metrics
- **Time Complexity**: How runtime grows with input size
- **Space Complexity**: Memory required for algorithm
- **Big-O Notation**: Upper bound of algorithm performance
- **O(1)**: Constant time (fastest)
- **O(n)**: Linear time
- **O(n log n)**: Linearithmic time
- **O(n²)**: Quadratic time (slow)

## Specific Terms
- **Pivot**: Element used for partitioning (Quick Sort)
- **Comparison**: Two elements checked (a < b)
- **Swap**: Exchange position of two elements
- **Partition**: Divide into left and right parts
- **Merge**: Combine two sorted arrays
- **Bucket**: Container for grouped elements (Radix)
- **Digit**: Individual number position (Radix Sort)

## Efficiency Terms
- **Best Case**: Optimal input scenario
- **Average Case**: Typical input behavior
- **Worst Case**: Poorest input scenario
- **Efficiency Score**: Composite performance metric

## Other Terms
- **CSV**: Comma-Separated Values (file format)
- **Responsive**: Adapts to different screen sizes
- **Chart.js**: JavaScript charting library
- **CDN**: Content Delivery Network
