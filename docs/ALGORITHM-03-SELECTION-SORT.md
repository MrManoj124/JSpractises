# Algorithm: Selection Sort

## Time Complexity
- **Best Case**: O(n²)
- **Average Case**: O(n²)
- **Worst Case**: O(n²)
- **Space Complexity**: O(1)

## Description
Selection Sort repeatedly finds the minimum element and places it at the beginning of the unsorted portion.

## Characteristics
- **Simple Algorithm**: Easy to understand and implement
- **Minimal Space**: In-place sorting
- **Inefficient**: Slow for large datasets
- **Predictable**: Same performance regardless of input

## When to Use
- Small datasets only (< 100 items)
- Educational purposes
- When memory is extremely limited
- When simplicity is priority

## Performance Notes
- Slow for large datasets
- Minimal memory overhead
- Reasonable for nearly-sorted data
