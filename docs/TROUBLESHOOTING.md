# Troubleshooting Guide

## Common Issues

### Issue 1: "No valid numbers found"
**Cause**: Input format incorrect or empty
**Solution**:
- Use comma or space separation
- Example: "5, 2, 8" or "5 2 8"
- Avoid special characters
- Check for typos

### Issue 2: Analysis button not responding
**Cause**: JavaScript not running or input invalid
**Solution**:
- Refresh page
- Check console for errors (F12)
- Verify numbers are entered
- Clear and re-enter data

### Issue 3: Charts not displaying
**Cause**: Chart.js not loaded or canvas issue
**Solution**:
- Check internet connection (CDN load)
- Refresh page
- Clear browser cache
- Try different browser

### Issue 4: Analysis taking forever
**Cause**: Too many numbers or slow system
**Solution**:
- Reduce number count
- Close other applications
- Use fewer than 5000 numbers
- Try different browser

### Issue 5: Numbers not showing in textarea
**Cause**: Paste issue or display glitch
**Solution**:
- Click in textarea first
- Try copying/pasting again
- Use manual entry
- Clear and try again

## Performance Issues

### Slow Analysis
- Reduce dataset size
- Close other tabs
- Disable extensions
- Restart browser

### Export not working
- Check browser privacy settings
- Allow downloads
- Disable popup blockers
- Try different browser

## Browser-Specific Issues

### Chrome
- Generally works best
- Check extensions

### Firefox
- May be slightly slower
- Disable extensions

### Safari
- May have permission issues
- Allow downloads in settings

### Mobile Issues
- Charts may be small
- Reduce dataset size
- Use landscape mode
