# Algorithm: Bubble Sort

## Time Complexity
- **Best Case**: O(n)
- **Average Case**: O(n²)
- **Worst Case**: O(n²)
- **Space Complexity**: O(1)

## Description
Bubble Sort compares adjacent elements and swaps them if they're in wrong order, repeating until sorted.

## Characteristics
- **Simple**: Very easy to understand
- **Adaptive**: Can detect sorted data
- **In-place**: Uses minimal extra space
- **Inefficient**: Poor performance on large datasets

## When to Use
- Nearly sorted data (where best case applies)
- Small datasets
- Educational demonstrations
- Minimal memory constraints

## Performance Notes
- Excellent for nearly-sorted data
- Terrible for random/reverse-sorted data
- Can be optimized with early termination
